# Хук-лаборатория

## Библиотека формул и их статистика
```!
cat knowledge/hooks-library.md
```

## Задача

Вход: $ARGUMENTS

Сгенерируй **10 хуков** по разным формулам из библиотеки. Для каждого укажи:
- формулу (hook_type)
- на какую эмоцию/мотив опирается (любопытство, несогласие, узнавание себя, страх упустить, обещание пользы)
- длину в символах

Затем оцени каждый по трём критериям (0–5) и отсортируй:
- **Стоп-скролл**: заставляет ли остановиться
- **Честность**: держит ли пост обещание хука (кликбейт = 0, это дисквалификация)
- **Соответствие голосу**: звучит ли как я по brand/voice.md

Дисквалифицируй хуки, которые обещают больше, чем даёт пост. Это разрушает доверие
и по нашим данным убивает повторные показы.

Верни топ-3 с рекомендацией и одной строкой почему.
