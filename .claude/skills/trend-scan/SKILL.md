# Трендскан

## Контекст бренда
```!
cat brand/positioning.md
head -40 brand/audience.md
```

## Что уже разбирали недавно
```!
ls -t trends/digest/ | head -3
tail -30 knowledge/learnings.md
```

## Задача

Период: последние $ARGUMENTS дней (если пусто — 3).

### Шаг 1. Сбор
1. Запусти `python3 scripts/keyword_scan.py --days $ARGUMENTS` — он положит сырые
   результаты Threads keyword_search в `trends/raw/<сегодня>/threads.json`.
   Если скрипт падает или токена нет — пропусти, но отметь это в дайджесте.
2. Через WebSearch найди 5–8 свежих материалов по темам ниши из positioning.md.
   Запросы формулируй с текущим годом. Ищи не «новости вообще», а сдвиги:
   новые данные, релизы, споры, смены практики.
3. Через WebFetch открой 3–5 самых содержательных источников целиком.
   Сниппетов недостаточно.

### Шаг 2. Отбор
Отсей: чистый шум, темы вне positioning, инфоповоды без моего угла зрения,
политику и срачи (см. «о чём не пишу»).

### Шаг 3. Скоринг
Для каждого выжившего сигнала посчитай:
- **R** (релевантность нише): 0–5
- **M** (импульс — насколько сейчас растёт обсуждение): 0–5
- **A** (мой угол — есть ли у меня непубличный опыт/данные по теме): 0–5
- **L** (живучесть — тема протянет неделю+): 0–3
- **C** (перенасыщенность — сколько уже написали): 0–3, где 3 = все написали

**Score = R × 2 + M × 2 + A × 3 + L − C × 2**

Вес A самый высокий намеренно: тема, где у меня есть свой опыт, всегда
лучше горячей темы, где я пересказываю чужое.

### Шаг 4. Дайджест
Запиши `trends/digest/<YYYY-MM-DD>.md`:

```
# Трендскан <дата>

## Топ-сигналы (score ≥ 12)
### [Название] — score N (R/M/A/L/C)
- Суть: 2 предложения
- Источники: URL, URL
- Мой возможный угол: 1–2 предложения
- Под какую рубрику: [из brand/rubrics.md]
- Срок годности: до <дата>

## Второй эшелон (score 7–11)
[тот же формат, короче]

## Отсеяно и почему
[одной строкой каждое — чтобы не сканировать это повторно]

## Что не удалось собрать
[источники, которые не открылись / API упал]
```

Не придумывай источники. Каждый факт — с URL. Если URL нет, сигнал не идёт в дайджест.
