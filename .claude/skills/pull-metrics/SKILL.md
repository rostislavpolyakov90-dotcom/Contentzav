# Сбор метрик

## Задача

1. Запусти `python3 scripts/fetch_posts.py --limit 50`.
   Скрипт тянет мои посты и их insights, дописывает снимки в `data/metrics.csv`.
2. Разбери вывод. Если скрипт вернул ошибку — не выдумывай данные,
   покажи ошибку и подскажи, что проверить (токен истёк / нет прав / лимит).
3. Сопоставь новые посты с черновиками: найди в `content/approved/**` файл,
   первые 40 символов текста которого совпадают с текстом поста.
   Совпало → перенеси атрибуты (rubric, hook_type, format, has_question,
   cta_type, experiment_id) в `data/posts.csv` рядом с `post_id`,
   перемести файл в `content/archive/`.
   Не совпало → добавь строку в posts.csv со `source: manual` и пустыми
   атрибутами, и попроси меня заполнить их вручную.
4. Отметь, по каким постам ещё не собраны снимки T+24h / T+72h / T+7d.

В чат: сколько новых постов, сколько снимков добавлено, что требует ручного заполнения.
Никакой аналитики здесь — только сбор. Анализ делает /weekly-review.
