## Задача

### Шаг 1. Что подтвердилось
Пройди по гипотезам в hypotheses.md. Для каждой:
- набрано n постов на вариант?
- разница медиан больше 25% и стабильна между неделями?
- **Да на оба** → переноси в learnings.md как подтверждённый вывод
- **Нет** → оставь в гипотезах, укажи, сколько ещё постов нужно
- **Опровергнуто** → перенеси в раздел «Опровергнутое» с датой. Опровержения ценны — они экономят будущие попытки.

### Шаг 2. Обнови learnings.md
Формат записи (append-only, старые не удаляем, а помечаем):

```
## L-014 · 2026-08-01 · подтверждено
**Вывод:** посты-разборы ошибок дают медианный ER 4.6% против 2.9% у всех остальных.
**Данные:** n=11 (рубрика) vs n=38 (остальные), период 6 недель, медианы по T+72h.
**Уверенность:** средняя — выборка небольшая, рубрика могла совпасть с сильными темами.
**Что меняем:** квота рубрики в rubrics.md 3/10 → 4/10.
**Пересмотреть:** при n=25 или через 8 недель.
```

### Шаг 3. Обнови hooks-library.md
Проставь фактические n и медианный ER у каждого типа хука.
Типы с n≥8 и ER ниже общей медианы на 30%+ — помечай `⚠️ слабый`, не удаляй.
Добавь 1–2 новые формулы, если в топ-постах видна структура, которой нет в библиотеке.

### Шаг 4. Предложи правки в brand/ и CLAUDE.md
**Не редактируй brand/*.md сам.** Выведи в чат конкретные диффы с обоснованием.
`CLAUDE.md` можешь править сам, но только разделы про формат и стилистику,
и только на подтверждённых выводах. Каждая правка — отдельная строка в чат-отчёте.

### Шаг 5. Новые эксперименты
Предложи 2 новых эксперимента в data/experiments.csv: что проверяем,
какая переменная, сколько постов на вариант, какой метрикой меряем.

### Шаг 6. Коммит
Сделай `git add -A && git commit` с сообщением вида:
`evolve: L-014 рубрика разборы +1 квота (n=11, ER 4.6% vs 2.9%)`

## Ограничения
- Не более 3 изменений правил за один прогон. Больше — и вы не поймёте, что сработало.
- Не удаляй старые выводы. Помечай `устарело` с датой и причиной.
- Если данных мало по всем направлениям — так и скажи, и ничего не меняй. «Ничего не менять» — валидный результат.
