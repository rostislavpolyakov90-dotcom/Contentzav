# QA-гейт

## Стандарты
```!
cat brand/voice.md
grep -A 30 "Запрещённая стилистика" CLAUDE.md
```

## Эталоны для проверки на сходство
```!
cat brand/swipe-file.md
```

## Задача

Проверь каждый черновик в `content/drafts/$ARGUMENTS/` по чек-листу.
Ставь ✅ / ⚠️ / ❌ по каждому пункту.

### Блок 1. Фактура (❌ = блок публикации)
- [ ] Каждый факт, цифра, цитата имеют источник в SOURCES или помечены как личный опыт автора
- [ ] Нет выдуманных кейсов, клиентов, исследований
- [ ] Нет утверждений об алгоритме платформы как о факте
- [ ] Нет обещаний результата, которые нельзя подтвердить

### Блок 2. Форма (❌ = блок)
- [ ] Длина ≤ 500 символов (посчитай реально)
- [ ] Первая строка работает автономно
- [ ] Нет вступления-разогрева
- [ ] Абзацы 1–2 строки, есть воздух
- [ ] ≤ 1 эмодзи, ≤ 1 хештег

### Блок 3. Стиль (⚠️ = переписать)
- [ ] Нет фраз из стоп-листа CLAUDE.md
- [ ] Нет AI-маркеров: симметричные триады, «не просто…, а…», обобщающая концовка-мораль
- [ ] Звучит по brand/voice.md — сверь по шкалам
- [ ] Нет корпоративных штампов

### Блок 4. Содержание (⚠️)
- [ ] Одна мысль, а не три
- [ ] Есть конкретика, а не только абстракции
- [ ] Хук не обещает больше, чем даёт пост
- [ ] Читатель может что-то сделать / изменить мнение / узнать себя

### Блок 5. Оригинальность (❌ при совпадении)
- [ ] Нет текстовых совпадений со swipe-file длиннее 6 слов подряд
- [ ] Структура заимствована, а фактура своя
- [ ] Пост не дублирует наш же пост из content/archive/ за последние 60 дней (проверь grep по ключевым словам)

### Блок 6. Риск (⚠️, решает человек)
- [ ] Тезис, за который придётся отвечать в комментариях — я готов
- [ ] Нет непреднамеренных обобщений о группах людей
- [ ] Нет медицинских/юридических/финансовых советов без дисклеймера

## Действия

- Всё ✅ → перемести в `content/approved/<неделя>/`, поставь `status: approved`
- Есть ⚠️ → **сам исправь** и перепроверь; если после двух попыток не чисто — оставь в drafts со `status: rework` и списком проблем
- Есть ❌ → оставь в drafts, `status: blocked`, объясни в файле причину

В чат: таблица `файл | вердикт | что исправлено | что требует решения человека`.
Не отчитывайся о том, что всё прекрасно, если это не так. Строгость здесь дешевле, чем репутационная правка задним числом.
