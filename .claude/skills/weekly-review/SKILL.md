# Недельный разбор

## Агрегаты
```!
python3 scripts/analyze.py --weeks 8
```

## Активные эксперименты
```!
cat data/experiments.csv
```

## Что уже знаем
```!
cat knowledge/learnings.md
```

## Задача

Напиши `reports/<YYYY-Www>.md`.

### Обязательная структура

```
# Неделя <номер> (<даты>)

## Цифры
| Показатель | Эта неделя | Прошлая | 4-нед. медиана |
Постов, суммарные просмотры, медианный ER, медиана комментариев,
прирост подписчиков, доля постов с ER выше личной медианы.

## Что сработало
Топ-3 поста. Для каждого: текст хука, рубрика, тип хука, цифры,
и **гипотеза почему** — с честной пометкой «единичный случай» либо
«подтверждает наблюдение из learnings #N».

## Что не сработало
Худшие-3. Тот же разбор. Особое внимание: провалы в рубрике, которая
обычно работает — это самый информативный сигнал.

## Срезы
- по рубрикам: медиана ER, n постов
- по типам хуков: медиана ER, n
- по длине (бакеты <250 / 250–350 / >350), n
- по дню недели и времени публикации, n
- с вопросом / без, n

Для каждого среза с n < 8 явно пиши: «данных мало, не решение».

## Эксперименты
Статус каждого активного: сколько постов набрано, промежуточный результат,
хватает ли данных для вывода.

## Гипотезы на проверку
2–3 конкретных, проверяемых, с указанием нужного объёма выборки.

## Рекомендации на следующую неделю
Максимум 3. Каждая — с указанием, на каких данных основана.
```

## Правила анализа

1. **Медиана, не среднее.** Один вирусный пост перекашивает среднее и создаёт ложные выводы.
2. **n указывать всегда.** Вывод без размера выборки — не вывод.
3. **Не путать корреляцию с причиной.** «Посты по вторникам собирают больше» может значить «по вторникам я пишу о том, что мне интереснее».
4. **Считать ER от просмотров:** `(likes + replies + reposts + quotes) / views`.
   Отдельно считать `reply_rate = replies / views` — комментарии дороже лайков.
5. **Учитывать возраст поста.** Пост вчерашний и пост недельный сравнивать только по снимкам одного возраста (T+24h к T+24h).
6. Если данные противоречат тому, что записано в learnings.md — **скажи прямо**, не сглаживай.
