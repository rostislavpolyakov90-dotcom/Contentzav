# Банк идей

## Свежий дайджест
```!
cat "$(ls -t trends/digest/*.md | head -1)"
```

## Что уже в банке (чтобы не дублировать)
```!
tail -60 content/ideas.jsonl
```

## Выводы, которые надо учесть
```!
cat knowledge/learnings.md
```

## Задача

Сгенерируй $ARGUMENTS идей (по умолчанию 20). Источники идей — в порядке приоритета:
1. Топ-сигналы дайджеста с высоким A (мой угол)
2. Развитие постов, которые хорошо сработали (см. learnings.md) — новый срез, не повтор
3. Возражения из brand/audience.md, ещё не закрытые контентом
4. Вечнозелёные темы рубрик, если сигналов мало

Соблюдай квоты рубрик из brand/rubrics.md.

Для каждой идеи — одна строка JSON в `content/ideas.jsonl` (append, не перезапись):

```json
{"id":"idea-2026-08-01-07","created":"2026-08-01","rubric":"разбор-ошибки","angle":"Одно предложение: какой поворот темы","claim":"Главный тезис поста","evidence":"Чем подкрепляю: свой кейс / цифра / источник URL","audience_segment":"А","source_signal":"название сигнала или empty","score":14,"status":"new","notes":""}
```

Скоринг идеи (0–20): релевантность сегменту (0–5) + сила тезиса, насколько он неочевиден (0–5) + есть ли у меня чем подкрепить (0–5) + вероятность отклика на основе learnings (0–5).

После записи выведи в чат таблицу: id | рубрика | угол | score, отсортированную по score.
Ничего не генерируй в виде готовых постов — только идеи.
